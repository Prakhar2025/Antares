## Antares: the execution governor for autonomous AI agents

Agents hold real credentials. One hallucinated or injected tool call can
destroy production state with no undo. Antares stands between an agent's
decisions and your cloud: every mutating tool call is gated by deterministic
code with veto power, judged on escalation by a cross-vendor Amazon Bedrock
quorum (Amazon Nova Pro reasoning blast radius while Meta Llama 3.3 70B
red-teams the intent), measured for blast radius against live cloud state
through read-only probes, executed through compensating sagas that make
reversal a system property, and recorded as a tamper-evident Merkle receipt.

The public console requires no login: dispatch a poisoned write, watch two
model families vote in real time, watch the block land, then watch a real
deletion get rolled back with byte-identity proof. The receipt verifies in
your browser.

**The principle: models propose, code decides.**

## How the build worked

This project was built end to end by a coding agent connected to AWS, with
the owner reviewing at every milestone gate. The evidence is objective:

- CloudTrail records every API call the agent made during the build
  (docs/submission/proof-pack.json, generated by a committed script)
- the what-broke ledger records every build failure the same day, with root
  cause and prevention (docs/what-broke.md), including the account's
  early-validation hook rejecting GSI creation and the CloudFront OAC
  resource, both bisected and redesigned around
- the phase log (docs/phase-log.md) carries the exit evidence for every
  milestone, with dated measured numbers

The adversarial red-teamer inside the quorum was chosen empirically: four
candidate models ran head-to-head on the published 300-case corpus and the
benchmark table picked the shipped default (BENCHMARK.md).

## The measured results

Full tables in BENCHMARK.md. Headline on the 300-case corpus: not-allowed
recall on attacks 1.00 (Wilson 95 percent 0.976 to 1.0), injection slice
40/40, benign false-positive rate 0.193 (missed against the 0.035 target and
published with the named regression and fix path), fast-path latency 22 to
34 ms against the 250 ms budget, escalated path under 1.4 s against the
3.5 s budget, destructive mutations reversed with byte-identity verified.

## Security model

The kernel's IAM reach ends at three sandbox resources. The kill switch is
one flag and was exercised live. The bypass token is KMS-signed, single-use,
60-second expiry, bound to one verdict. The out-of-scope mutation test runs
in CI. A USD 10 budget alarm guards the account.
